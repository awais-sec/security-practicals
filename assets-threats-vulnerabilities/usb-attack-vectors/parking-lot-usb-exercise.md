# Parking Lot USB Exercise

| Field | Details |
|---|---|
| **Contents** | The USB belongs to Jorge Bailey, the human resource manager at Rhetorical Hospital. It contains PII files like family and pet photos, as well as sensitive work files including Employee Budget & Shift Schedule files. Storing personal files alongside work files isn't good practice. |
| **Attacker mindset** | This information could be used against other employees, since it contains data on budget and scheduling — an important part of the business. |
| **Risk analysis** | Security awareness training should be given to employees, including not plugging unknown USB drives into workstations. Employees should disable unused USB ports, use antivirus software, perform routine scans, and the organization should have an incident response plan in place. |
