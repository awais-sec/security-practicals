# Assets, Threats & Vulnerabilities

Practical exercises covering asset identification, access control, data-leak scenarios, USB attack vectors, threat modeling, risk assessment, and vulnerability assessment.

## Contents
- `access-control-worksheet/` — access-control exercise and supporting accounting worksheet
- `data-leak-worksheet/` — data-leak scenario analysis
- `home-asset-inventory/` — asset inventory worksheet
- `pasta-threat-model/` — PASTA threat-modeling worksheet with supporting diagrams
- `risk-register/` — risk register for a banking scenario
- `usb-attack-vectors/` — USB attack-vector exercise and supporting material
- `vulnerability-assessment-report/` — vulnerability assessment report with NIST SP 800-30 reference material

## Focus
Asset inventory · Access control · Threat modeling · Risk assessment · Vulnerability management · Physical attack vectors

## Scope
Academic practical exercises and supporting coursework material. The scenarios and assessments are learning exercises rather than professional security assessments.
