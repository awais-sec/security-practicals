# security-practicals

**Security Practicals & Exercises** — Documented hands-on practicals covering network hardening, OS hardening, incident response, and security auditing aligned to NIST and ISO 27001 frameworks.

---

## Practicals

| # | Title | Framework | Focus |
|---|---|---|---|
| 01 | Network Hardening Analysis | NIST | Firewall rules, access controls, segmentation |
| 02 | OS Hardening Techniques | CIS Benchmarks | Services, audit policies, least privilege — Linux & Windows |
| 03 | Network Layer Communication Analysis | OSI / TCP-IP | Protocol inspection, anomalous packet identification |
| 04 | NIST Incident Response Exercise | NIST SP 800-61 | Full IR lifecycle — preparation through post-incident |
| 05 | Security Audit | NIST CSF / ISO 27001 | Gap analysis, control assessment, findings report |

---

## Frameworks Applied

- **NIST SP 800-61** — Computer Security Incident Handling Guide
- **NIST Cybersecurity Framework (CSF)** — Identify, Protect, Detect, Respond, Recover
- **ISO/IEC 27001** — Information Security Management
- **CIS Benchmarks** — OS hardening baselines
