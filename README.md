# Security Practicals

A practical archive of cybersecurity exercises covering **network security, system hardening, incident response, security auditing, vulnerability assessment, access control, threat modeling, and security analysis**.

The repository preserves hands-on coursework as structured reports, worksheets, supporting resources, and analysis material. It is intentionally separate from the more polished project work in the rest of the portfolio.

## Practical Work

| Area | What It Covers |
|---|---|
| [Assets, Threats & Vulnerabilities](assets-threats-vulnerabilities/) | Asset inventory, access control, data-leak scenarios, USB attack vectors, PASTA threat modeling, risk registers, and vulnerability assessment |
| [Manage Authorization](manage-authorization/) | Linux file permissions and authorization review |
| [Network Attack Analysis](network-attack-analysis/) | SYN flood incident analysis and network interruption investigation |
| [Network Hardening Analysis](network-hardening-analysis/) | Security risk assessment, hardening methods, and security controls |
| [Network Layer Communication Analysis](network-layer-communication-analysis/) | Network traffic analysis using TCP/HTTP communication data |
| [NIST CSF Incident Response](nist-csf-incident-response/) | DDoS incident analysis using the NIST Cybersecurity Framework |
| [OS Hardening Techniques](os-hardening-techniques/) | OS security incident analysis, DNS/HTTP traffic review, and tcpdump interpretation |
| [Security Audit](security-audit/) | Botium Toys audit scope, risk assessment, controls, and compliance checklist |
| [Security Standards, Policies & Frameworks](security-standards-policies-frameworks/) | Security organization and framework-related exercises with reference material |
| [SQL Query Filters](sql-query-filters/) | SQL filtering and query-analysis practice |

## Practical Workflow

```text
Scenario / Exercise
        ↓
Identify Assets, Risks & Attack Surface
        ↓
Analyze Evidence / Requirements
        ↓
Apply Security Controls or Framework
        ↓
Document Findings
        ↓
Record Recommendations / Lessons Learned
```

## Evidence & Resources

Several exercises include supporting spreadsheets, raw traffic/log material, worksheets, reference documents, and presentation resources. These are kept with the relevant practical rather than duplicated elsewhere in the portfolio.

## Scope

This repository primarily contains **academic coursework and practical exercises**. The material demonstrates applied learning and structured analysis; it should not be interpreted as independent professional security assessments unless explicitly stated in an individual report.
