# Security Risk Assessment Report: Network Hardening

## Part 1: Select up to three hardening tools and methods to implement

Having default passwords and sharing passwords with each other tells us that the employees are untrained, which leads them into unethical activities. Training them on ethics in cybersecurity is a first and compulsory step towards a strong security posture. Firewalls, strong password policies based on NIST guidance, and MFA are some of the tools and methods that should be implemented for this risk assessment.

## Part 2: Explain your recommendations

Ethics in cybersecurity is the first and foremost thing every employee should be aware of, as sharing passwords and using default passwords can lead to DoS attacks on the company.

1. Strong password policies based on NIST guidance can help the company overcome its weak password management.
2. Installing firewalls, maintaining them, disabling unused ports, and port filtering leads to a more controlled network, which can stop an attacker from penetrating the internal network through unwanted ports.
3. Multi-factor authentication (MFA) requires users to verify their identity in two or more ways. MFA options include a password, PIN, badge, one-time password (OTP) sent to a phone, fingerprint, and more. This security measure makes it much harder for an attacker to gain access to the internal network.
